# Comparison fixture v1

`before/` and `after/` are two states of one tiny Python repository. `expected_comparison.json` is the
reviewed `SnapshotComparison` of the Python analyzer's snapshots of them (repository
`github.com/xraymyrepo/comparison-fixture`, placeholder commits `1111…` → `2222…`, default parameters), in
canonical order with one record per line. Line endings are LF (`.gitattributes`), so blob ids are stable.

`tests/insights/test_comparison.py` checks the whole document and, separately, spells out every case below.

| Case | Files | Expected |
|---|---|---|
| real code change | `shop/pricing.py` | file `modified`; `price_with_tax` `modified`; `Cart`, `Cart.total` `unchanged` |
| comments and whitespace only | `shop/util.py` | file `modified` (bytes changed); `slugify` `unchanged` (same tokens) |
| same body, edited file | `shop/checkout.py` | file `modified`; `checkout` `unchanged` |
| deleted file | `shop/legacy.py` | file and `old_discount` `removed` |
| added file | `shop/catalog.py` | file and `find` `added` |
| identical move | `shop/old/shipping.py` → `shop/new/shipping.py` | file and `shipping_cost` `moved` (`same_content_hash`, medium); `shop/old` removed, `shop/new` added |
| ambiguous move | `shop/a/template.py` → `shop/b/…`, `shop/c/…` (identical) | one `removed`, two `added`, all three `move_ambiguous`; nothing guessed |
| trivial move | `shop/consts.py` → `shop/settings/consts.py` | no declarations: `removed` + `added`, not flagged |
| file stops parsing | `shop/report.py` (syntax error after) | file `modified`; `summarize` `undetermined` (low), not removed |
| edge removed | `pricing.py` → `legacy.py#old_discount` | `removed` |
| edge added | `pricing.py` → `catalog.py#find` | `added` |
| edge into a moved file | `checkout.py` → `…/shipping.py#shipping_cost` | `modified`, medium: ends matched through the move, specifier rewritten (`.old.shipping` → `.new.shipping`) |
| edge of an unparsed file | `report.py` → `pricing.py#Cart` | `undetermined` (low): `after` cannot show `report.py`'s imports |
| edge unchanged | `pricing.py` → `util.py#slugify` | counted: `unchanged_edges = 1` |

The JSON is generated by the comparison and then reviewed line by line against this table.

## Change risk

`expected_change_risk.json` is the reviewed `ChangeRiskAssessment` of that comparison, with default parameters
(docs/insights/change-risk-v1.md). `tests/insights/test_change_risk.py` checks it whole and spells out the cases
below.

**Confidence across the fixture.**
- `report.py` stops parsing in `after`, so `to` has a blind spot. Every subject assessed in `to` has
  `hidden_dependencies`, and its `no_dependent_test` factor is listed with 0 points instead of scoring: missing
  evidence is not counted either way.
- Removed files are assessed in `from`, which has no blind spot, so they keep `high` confidence.

| Subject | Change | Level (points) | Confidence | Why |
|---|---|---|---|---|
| `shop/legacy.py` | removed | high (5: kind 2, interface 2, dependents 1) | high | `old_discount` removed; `pricing.py` imported it and `report.py` depends on `pricing.py`, both still there. `pricing.py` dropped the import, so nothing dangles: `unresolved_after_removal` does not fire |
| `shop/a/template.py` | removed | high (4: kind 2, interface 2) | high | the ambiguous move is not credited: removing a file is removing it |
| `shop/consts.py` | removed | medium (2: kind 2) | high | no declarations, no dependents |
| `shop/new/shipping.py` | moved | medium (2: kind 1, dependents 1) | medium | `checkout.py` imports it; the move itself is `medium` |
| `shop/util.py` | modified | medium (2: kind 1, dependents 1) | medium | only comments and whitespace changed, but `pricing.py` depends on it; no interface change |
| `shop/catalog.py` | added | low (1: dependents 1) | medium | new, and `pricing.py` already imports it |
| `shop/checkout.py` | modified | low (1: kind 1) | medium | no dependents |
| `shop/pricing.py` | modified | low (1: kind 1) | low | `undetermined_changes`: `after` cannot show whether `report.py` still imports it (its only dependent) |
| `shop/report.py` | modified | low (1: kind 1) | low | `undetermined_changes`, `incomplete_extraction`: it failed to parse in `after` |
| `shop/b/template.py`, `shop/c/template.py`, `shop/settings/consts.py` | added | low (0) | medium | new, nothing depends on them |

Assessment: level `high`, confidence `low`, not conclusive. Twelve subjects, none excluded by origin. When the fixture,
the analyzer's output or the algorithm changes, regenerate it and review the diff in the same commit.
